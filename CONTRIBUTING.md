# Contributing to Algorithm Forge Ultra

Thanks for helping improve Algorithm Forge Ultra!

## Before opening an issue

- Search existing issues to avoid duplicates.
- Include your browser and operating system.
- Describe the exact steps to reproduce the problem.
- Include expected versus actual behavior and a screenshot or console error when useful.
- For algorithm issues, provide a small input that reproduces the incorrect result.

## Pull requests

1. Keep changes focused and explain the problem they solve.
2. Preserve the existing algorithm catalogue unless the maintainers explicitly change project scope.
3. Avoid adding dependencies or a build step without a clear need.
4. Test the changed demo and run the built-in browser test at `index.html#autotest`.
5. Check desktop and narrow/mobile layouts for UI changes.
6. Update the README or test report when behavior or setup instructions change.

## Development

The app is static HTML, CSS, and JavaScript. Open `index.html` locally or use a static server. The primary application code is in `js/app.js`; styles are in `css/styles.css`.

## Code of conduct

Be respectful, constructive, and welcoming. Critique code and ideas, not people.
